# 1.0.4

- 新增官方降级包一键推送与安装唤起（基于 ColorOS 助手逆向成果，免 Root，免解 BL 锁）。
- 随包集成官方降级伴生应用（`OTA_17.apk` 与 `OTA_113.apk`），自动检测已连接设备的 Android / ColorOS 版本并适配旧版及 11.3+ 现代版系统。
- 前置安全核检机制：推送前深度校验固件包，严格拦截增量包用于降级，核对适用机型与当前连接设备代号是否匹配（跨机型强阻断），校验固件大小及完整性。
- 手机端存储容量预检：推送前自动执行 `df` 检查 `/sdcard` 剩余空间，不足时友好拦截并提示清理，避免传输中途损坏。
- 高可靠固件推送：实时监测 ADB 推送字节数与速率，支持中途安全取消并清理残留，推送完成后自动核验手机端文件大小。
- 自动化协议触发：传输完成后自动通过广播唤醒伴生服务，向 `DataSharedProvider` 写入本地包路径及 `forbid_check_update` 标记，并唤起官方系统更新组件（`EntryActivity`），手机端亮屏弹出官方本地降级确认窗口。
- 界面双入口支持：在“固件获取”页面支持对已选固件一键推送，同时支持“推送本地降级包…”直接浏览选择电脑上的任意 `.ozip` 或 `.zip` 官方固件。
- 单元测试扩展至 45 项，覆盖安全核验、APK 匹配、伴生检测、存储计算、Legacy/现代版 Activity 调起及完整工作流。

# 1.0.3

- 新增“ADB 已连接设备 / 手动选择机型”切换，不连接手机也可查询固件、下载和在线选择镜像。
- 内置来自 Google 公开设备列表的 1,185 个 OPPO / 一加 / realme 机型条目，支持名称、型号、设备代号搜索和自定义型号。选择后填入公开型号、代号及可确认的地区默认值，NV 随地区填入，可手动修正。
- 手选不套用上一台设备的 SN、项目号、GUID、DUID、当前版本和组件；手选模式禁用 root 按钮。刷新 ADB 保持手选查询对象，切回 ADB 模式恢复设备读取。
- 机型或地区更换后，固件列表和在线解包来源按新对象更新，清除旧的在线镜像清单。本地文件可继续解包。
- 防止切换到手选模式后仍触发之前排队的 ADB 自动查询。查询和解包任务执行期间锁定机型选择。
- 39 项自动化测试通过；无需 ADB/root，实网查询 Find X8（PKB110）取得官方全量包，读取 47 个镜像并提取、核验 8 MiB 的 init_boot。

# 1.0.2

- 修复历史增量漏查：同时使用当前设备基线及已记录的历史组件基线，补齐 server_auto 增量请求。
- 增量查询不再用其他分支的成功版本替换源 OTA，避免破坏源版本与组件的配对；增量基线标注使用请求的源 OTA，不再误用手机当前系统版本。
- 保存普通 ADB 读到的固件组件基线，按机型、地区、NV 隔离。附带两份来自官方全量包的 PHY110 国区公开基线，可在新电脑上复现已确认的历史增量查询。
- 根据服务器 type=0/1 判定增量/全量候选，再用 payload manifest 确认；长基线列保持固定初始宽度，完整值可在详情和悬浮提示中查看。
- 填入 GUID 后仍保留公开 v3 增量查询，并记录非敏感的接口类型以便按原接口刷新链接。
- 实网确认并验证 `PHY110_16.0.10.500 → 17.0.0.100` 增量包。回归测试共 32 项，另验证真实增量 init_boot 合成。

# 1.0.1

- 在“设备与参数”新增“尝试 root 获取 GUID 和 DUID”按钮。只有手动点击才请求 su；默认启动、刷新连接、查询固件和打包自检均不使用 root。
- 读取当前选中设备的系统 GUID 与 OTA 缓存 DUID，校验格式后填入。支持部分成功，失败保留已有输入，设备之间隔离，仅存内存，不将完整标识写入日志或配置。
- 修正底部提示区域：提示文字占用可用宽度，固定右侧按钮位置，保留两行行高；修复查询完成文本被挤成窄列的问题。进度条加高，避免百分比显示被裁切。
- 查询完成提示明确说明返回条数包含重复记录。

测试包括默认扫描不调用 su、指定设备读取、授权失败/超时、无效或缺失标识、取消、按钮手动触发与设备隔离，以及 1060/1380 像素窗口宽度下的底部文字布局。
