## 界面与发布验证

实际 Windows 窗口已显示中文设备卡片、查询参数、设备选择和刷新控件，读取真实连接信息；筛选和镜像勾选另由 Qt 自动化验证。打包版本使用 `--self-check REPORT_JSON` 检查 Qt 三页初始化、随包 ADB 读取以及两个随包解包引擎；最终结果记录于 `packaged-check.json`。

独立打包测试发现开发环境 PATH 中的 Poppler ICU 库与 Qt 所需的 Windows ICU API 冲突；已移除误收集的库，并在构建脚本中隔离该 PATH 条目。最终程序自检同时覆盖 AES-CTR、RSA-OAEP、随包 ADB 和两个解包引擎。指定版本的签名链接重新查询已用真实 ColorOS 17 包验证，返回相同 OTA 和包 MD5。

限制：没有下载并提取整包全部镜像；未验证所有机型/地区；未以真实增量系统包覆盖每一种差分操作；厂商受限测试/PKI 授权及撤包状态仍由服务器决定。
